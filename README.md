# Тренажёр по теореме Виета

Учебное веб-приложение на русском языке для школьников 8-го класса. Помогает освоить решение приведённых квадратных уравнений `x² + px + q = 0` с целыми действительными корнями.

Приложение работает в браузере. Серверная часть, база данных, регистрация и авторизация отсутствуют.

## Возможности

Разделы доступны независимо: теорию и обучение можно пропустить.

- **Изучить теорию** — формулы Виета, объяснение коэффициентов, раскрывающиеся пошаговые примеры с положительными, отрицательными, совпадающими и нулевыми корнями, типичные ошибки со знаками.
- **Практика с обучением** — три задания уровней easy, medium и hard. В каждом нужно последовательно найти сумму, произведение и два корня. Подсказки бесплатны, баллы не начисляются, число попыток не ограничено. Доступен просмотр полного решения.
- **Проверить знания** — девять разных уравнений: по три каждого уровня в порядке easy → medium → hard. Есть подсказки, разбор решения и итоговая таблица результатов.
- **Сохранение сессии** — автоматическое восстановление режима, заданий и прогресса после обновления страницы через localStorage.

Интерфейс адаптируется к ширине экрана. Поля имеют подписи, сообщения об ответах используют область уведомлений, раскрывающиеся примеры доступны с клавиатуры.

## Математика и баллы

Генератор выбирает целые корни и получает коэффициенты по формулам `p = −(x₁ + x₂)` и `q = x₁ · x₂`. Поэтому целые действительные корни гарантированы. Повторов уравнений внутри проверки знаний нет.

Стандартные задания:

| Уровень | Корни |
| --- | --- |
| easy | Различные положительные числа от 1 до 6 |
| medium | Модули от 1 до 9: одна пара отрицательных корней и две пары с разными знаками |
| hard | Модули ненулевых корней от 10 до 20: различные корни, нулевой корень, совпадающие корни |

Диапазоны и состав задаются в `src/core/rules.ts`; допустимый максимум модуля корня в настройках — 100. В обучающей практике выбирается по одному заданию каждого уровня; сложное задание — с совпадающими корнями.

В самостоятельной проверке действуют правила:

| Уровень | Без подсказки | С подсказкой | Готовое решение |
| --- | ---: | ---: | ---: |
| easy | 1 | 0,5 | 0 |
| medium | 2 | 1 | 0 |
| hard | 3 | 1,5 | 0 |

Максимум — **18 баллов**. Ошибки до правильного решения не снижают результат. Повторные подсказки не увеличивают штраф, повторная проверка завершённого задания не начисляет баллы заново. Итог вычисляется из результатов отдельных заданий.

Порядок введённых корней не важен. Совпадающий корень вводится в оба поля. Принимаются целые числа со знаком, пробелами по краям и типографским минусом `−`. Пустые поля, дроби, выражения, экспоненциальная запись и числа вне безопасного целочисленного диапазона отклоняются. Ошибки формата отделены от неправильного решения и не учитываются как неправильные попытки.

## Технологии

- React 19 и React DOM — интерфейс и Hooks.
- TypeScript 6 — типы и проверка кода.
- Vite 8 с плагином React — разработка и сборка.
- CSS — оформление и адаптивность, без библиотеки компонентов.
- ESLint 10 и правила React Hooks — статическая проверка.
- Встроенные `node:test` и `node:assert/strict` — автоматические тесты без отдельной тестовой библиотеки.
- localStorage — локальное сохранение JSON.

## Архитектура

```text
src/
  core/                      Математика, генерация, ответы, баллы, тренировка
    __tests__/               Тесты ядра, обучения и сохранений
    rules.ts                 Диапазоны, уровни и базовые баллы
    types.ts                 Общие типы
    equations.ts             Коэффициенты из корней и идентичность уравнений
    generator.ts             Генерация девяти уникальных заданий
    answers.ts               Разбор ввода и проверка корней
    scoring.ts               Расчёт баллов
    training.ts              Неизменяемые переходы самостоятельной тренировки
  learning/practice.ts       Шаги и переходы обучающей практики
  persistence/
    session.ts               Формат, проверка, чтение и запись сохранения
    useActiveSession.ts      Связь сохранения с состоянием React
  components/
    Theory.tsx               Теоретический раздел
    LearningPractice.tsx     Обучающая практика
  App.tsx                    Главная, навигация, самостоятельные задания и итоги
  presentation.ts            Форматирование чисел и уравнений
  App.css                    Стили компонентов
  index.css                  Общие стили
  main.tsx                   Подключение React к HTML
public/                      Статические ресурсы
index.html                   HTML-страница
```

Математическое ядро не зависит от React. Компоненты передают действия в функции управления состоянием. Отдельной библиотеки маршрутизации нет: разделы переключаются через React-состояние. Переход к итогам после девятого задания выполняется кнопкой, чтобы ученик сначала увидел обратную связь.

## Локальный запуск

Проверенная среда: **Node.js 22.22.3** и npm. Используйте эту версию Node.js или более новую совместимую версию ветки 22: тесты запускают TypeScript напрямую с флагом `--experimental-strip-types`.

Из корня полученной копии проекта:

```bash
npm ci
npm run dev
```

Откройте адрес, напечатанный Vite в терминале. Для остановки нажмите Ctrl+C. Переменные окружения и секретные ключи для запуска не требуются.

## Проверки и сборка

| Команда | Назначение |
| --- | --- |
| `npm test` | Все автоматические тесты из `src/core/__tests__/` |
| `npm run lint` | Проверка ESLint |
| `npm run build` | Проверка TypeScript (`tsc -b`) и сборка Vite в `dist/` |
| `npm run preview` | Локальный просмотр уже выполненной сборки |

Перед подготовкой публикации:

```bash
npm test
npm run build
npm run lint
npm run preview
```

Тесты проверяют формулы Виета, генерацию без повторов, ввод, баллы, блокировку завершённых заданий, шаги обучения и сериализацию сохранений, включая ошибки хранилища. Тесты localStorage используют имитацию хранилища; автоматических браузерных тестов нет.

## Сохранение прогресса

Используется один ключ `vietas-trainer.active-session`, формат JSON версии `1`. Для каждой новой сессии создаётся уникальный ID.

Сохраняются текущие уравнения, индекс задания, введённый текст, шаг обучения, обратная связь, использование подсказок, неправильные попытки и начисленные баллы, где применимо. Сохраняется также выбор экрана результатов. Новые задания при восстановлении не генерируются.

Чтение и проверка выполняются до первого отображения сессии; пустое начальное состояние не перезаписывает сохранение. После действий сессия сохраняется синхронно. Неподходящая версия, повреждённый JSON или некорректное состояние приводят к открытию главной с сообщением. Ошибки доступа и записи перехватываются; приложение не обещает успешное восстановление, если запись не удалась.

При выходе из незавершённого занятия требуется подтверждение. Отмена оставляет прогресс. Подтверждённый выход удаляет сохранение; при невозможности удаления выход не выполняется. Если сохранение уже заменено другой вкладкой, выход из старой вкладки не удаляет чужую новую сессию. При неудачной замене существующей сессии сохраняются предыдущие данные и экран.

Обычное обновление страницы после успешного сохранения не вызывает предупреждения. При ошибке сохранения приложение пытается записать данные перед уходом и, если это невозможно, запрашивает стандартное подтверждение браузера.

## Подготовка статического хостинга

Для публикации нужны файлы из `dist/`, создаваемые командой `npm run build`. Сервер Node.js на хостинге не нужен. Автоматическое развёртывание пока не настроено.

По умолчанию сборка рассчитана на корень сайта. Для размещения в подпапке, например на проектном GitHub Pages, укажите реальный путь репозитория при сборке:

```bash
npm run build -- --base=/имя-репозитория/
```

Для публикации используйте HTTPS: приложение создаёт ID через `crypto.randomUUID()`, доступный в защищённом контексте. При локальной разработке подходит localhost. Открытие `index.html` напрямую через `file://` не является способом запуска.

В репозиторий входят исходники, настройки, `package.json` и `package-lock.json`. Папки `node_modules/`, `dist/`, временные файлы и локальные файлы секретов исключены через `.gitignore`. Переменные Vite, попадающие в клиентскую сборку, нельзя использовать для хранения секретов.

## Известные ограничения

- Есть одно сохранение на origin сайта (протокол, домен и порт). Истории результатов и синхронизации между устройствами нет. После смены адреса прежнее сохранение недоступно.
- Очистка данных браузера удаляет прогресс. В приватном режиме или при запрете localStorage сохранение может не работать. Если хранилище недоступно, текущая сессия может остаться только в памяти вкладки.
- Проверка конфликтов между вкладками защищает от обычной записи устаревшего состояния, но не является атомарной блокировкой одновременно работающих вкладок. Рекомендуется проходить занятие в одной вкладке; состояние вкладок автоматически не синхронизируется.
- При полностью недоступном хранилище удалить старое сохранение программно невозможно; приложение сообщает об ошибке.
- Сохраняется только текущая сессия, включая её финальный экран до выхода или начала новой. Теория и раскрытие её примеров не сохраняются.
- Правильные ответы находятся в браузере вместе с приложением. Это учебный инструмент, а не защищённая экзаменационная система.
- Поддерживаются приведённые квадратные уравнения с целыми корнями; дробные и комплексные корни не входят в задания.
- Нужен современный браузер с JavaScript и поддержкой используемых веб-API. Проверка экранными дикторами, всех мобильных браузеров и полностью одновременной записи из вкладок не автоматизирована.
